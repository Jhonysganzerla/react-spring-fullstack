# react-spring-fullstack

Aplicação fullstack com **Spring Boot** no backend e **React** no frontend. Inclui autenticação JWT e API REST.

## Stack
- **Backend**: Java 17, Spring Boot, Spring Security, JPA
- **Frontend**: React, fetch/axios
- **Auth**: JWT

## Como rodar
```bash
# backend
cd backend
./mvnw spring-boot:run
# frontend
cd ../frontend
npm install && npm start
```
